01 · The problem

LLMs have architectural amnesia

A deployed language model's weights are frozen. Everything it "learns" in a conversation lives only in the context window — and dies with it.

What the model has

A context window — perfect short-term memory that is wiped after every conversation.

What it lacks

Consolidation — any path from "I just read this" to "I now know this," the way experiences become knowledge overnight for us.

The usual workaround

RAG bolts a database onto the prompt. Useful — but it is a lookup, not memory. The model never actually learns anything.

The research question: can a frozen, pretrained model learn new facts permanently, from a single exposure, without destroying what it already knows?

02 · The inspiration

Biology already solved this — with sleep

Your brain faces the same problem every day. Follow the pipeline:

1 · Tagging

Surprising experiences get flagged at the synapse by prediction-error tags (synaptic tagging & capture). A bookmark, not yet a memory.

2 · Competition

Tags compete for a limited pool of plasticity proteins (PRPs). Only what matters wins the resources to become permanent.

3 · Replay in sleep

Deep inside, the hippocampus replays the winning experiences — again and again through the night — training the cortex.

4 · Consolidation

Episodic traces become durable knowledge across the neocortex — written in, without overwriting the old.

Continuous, selective, single-exposure learning that does not forget itself.

Exactly the specification an LLM lacks

SLEEP

Synaptic Learning through Error-driven Encoding & Plasticity

03 · The proposal — sleep, installed into a transformer

The patient · a frozen LLM

A pretrained transformer — 12 slabs standing in for 28 layers. Tokens flow up, a prediction comes out the top, and the weights never change.

The dismantle

Every layer is two organs: a thin attention plate — the librarian, it looks things up — and a thick MLP plate — the filing cabinets. Keep that difference in mind.

1 · Tagging layer

A scanner on the token stream. It watches the model's own surprise on every token it reads — no second model, just its own loss.

in : every token t
     e_t = −log p(x_t|x_<t)   # surprise
     z_t = (e_t − μ) / σ
out: spans where z_t > 1.5
2 · KV memory bank

A one-shot episodic store docked onto the top-third attention plates. No retraining — memories are injected straight into attention.

in : K,V of the tagged episode
     stored once, no gradients
read: Attn(Q, [K_mem;K], [V_mem;V])
      top-k gate picks who speaks
3 · PRP allocator

The budget office. Permanence is expensive, so tags compete — and most lose.

in : all tags
     score = .35·surprise + .30·access
           + .15·xref     + .20·recency
out: top-K winners, hard budget B
4 · Sleep engine

The night shift. Runs offline, when nothing is being asked.

for m in winners:
    replay m             # rehearse
    step W_cons          # learn
    clip ‖ΔW‖ ≤ δ_max    # rails
    verify, else rollback
wipe the memory bank     # morning
5 · Consolidation adapters (W_cons)

Thin trainable wafers — the only part that ever learns. The base model stays frozen forever.

W′ = W + (α/r)·B·A     # LoRA
placed: attention, top ⅓
— where biology pointed.
Watch this address.
The loop, closed

Same frozen transformer — now with a hippocampus, a budget office, and a night shift. That is SLEEP.

reads once & flags surprise keeps only what wins the budget consolidates while it sleeps base weights untouched

05 · How we grade it

The exam, in three numbers

200 fictional facts · each seen exactly once · the memory bank is wiped before every question — only the weights may answer.

MC

Multiple-Choice recognition

Four options, one correct — can the model pick the right answer? Chance is 0.25. Recognition is the easy mode: a faint nudge from memory is enough.

DRA

Delayed Recall Accuracy

A free-form question, answered from weights alone, greedy decoding — no lucky guesses. Score: how many of the expected key details appear. The real test — recall, not familiarity.

BCP

Base Capability Preservation

The damage meter: did learning this break anything else?

BCP = PPL_after / PPL_before     1.00 = unharmed · ≤1.05 = target · >2 = damaged

Every run must answer three questions: Does it recognize? Can it recall? Did anything else break?

0.28 · what it is

Recognition on stored facts. Show a fact once, then quiz: four options, one right. Stored facts were picked correctly 28% of the time. How we got it: 200 facts → one wake pass stores them → the quiz → fraction correct.

0.12 · the control

The same quiz on facts the tagger skipped: 12%. The difference — +0.16 — is the memory speaking. Recognition genuinely works: the stored trace tilts the choice.

0.00 · the real test

Free-form recall. Same stored facts — but now the model must say the answer: 50 tokens, scored for the fact's key details. It produced zero. Not low. Zero. The memory that tilts a choice cannot drive a sentence.

09 · The low point

Recognition without recall — on every model we could test.

The system certified its own learning. 93–100% of those certificates were false.

The principled repair: 16 runs. Recall never moved.

A one-line textbook baseline beat our five-organ architecture — 0.070 vs 0.012.

So the paper told the truth. Its title: “…Empirical Limits of Biologically-Inspired Memory Consolidation.”

…unless we were asking the wrong question.

10 · The turn — the repair, live on the table

The pre-mortem

Assume the paper is wrong — where is the bug? Re-examine every choice, starting with the one we never questioned: where we write.

The wrong address

Our wafers sit on top-third attention — chosen because the biology analogy said "neocortex lives up here." But attention retrieves; it doesn't store. We were handing facts to the librarian.

The right address — the MLP

An MLP plate is two big matrices back to back: pattern in → stored association out. A key→value cabinet. Causal tracing (ROME, MEMIT) finds facts here — in the middle layers.

edit a mid-stack MLP  → the fact changes
edit attention        → almost nothing
the map was public all along
The move

Same wafers, new address. Two fixes ride along: teach each fact in 20+ wordings, distilled from the model's own in-context answers.

placement : attention top-⅓  →  MLP mid-⅓
replay    : 1 wording        →  20+
teacher   : itself, with the fact in context
The third culprit — the safety clip

Why it exists: after every training step, each weight change is capped, so learning can never wreck the model. Insurance.

after each step:
  ΔW ← clip(ΔW, ±δ_max)
set in April: δ_max = 0.01
Right-sized, not removed

At 0.01 the clip erased the write after training made it — recall 0.007, again. Keep the insurance, loosen the grip.

δ_max : 0.01  →  0.1
recall: 0.007 →  0.21 ± 0.02
damage: still under 1.0
SLEEP v2

Same organs. Right addresses. Right-sized rails.

write where facts live teach the fact, not the sentence safety that helps, not strangles

12 · The long run — ten cycles, line by line

the green line

SLEEP v2, one full run — recall over every fact seen so far, ten cycles of twenty new facts each. Solid = seed 0.

the dotted twin

Same config, different dice — seed 1, drawn dotted. The twins agree almost everywhere. Two seeds agreeing is what trust looks like.

the blue pair · EWC

The standard continual-learning baseline. Its penalty preserves the model beautifully — and it learns almost nothing: it hovers near 0.05. Preventing forgetting ≠ creating knowledge.

the amber pair · naive

Plain fine-tuning, both seeds — same level as EWC. SLEEP v2 holds ≈3× above both baselines for the entire horizon, on both seeds.

now the cost

Same six runs, now the damage meter. SLEEP v2 drifts gently, ≈1.0 → 2.2 — no cliffs, no explosions. The old "plateau lottery" is gone.

all in one band

The baselines pay a similar damage bill on this model. Elsewhere they don't: at 1.5B, naive detonated to ×24. SLEEP held ×2.4.
